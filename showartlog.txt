    BUGFIX !!!!
    Do you ever open up thousands of files in one directory?  It takes FOREVER.
    
    I tested it by creating a directory with 10,000 files in it.  I thought maybe the data structure is slowing down as it fills up.  So I would expect it to start fast and then slowdown.
    Nope.  I had it print the time every 100 files.  It took about 2 seconds for every 100 files.  Which is 200 (!!!) seconds for 10000 files!  Same time spent for every 100 files.

    long time = fs->Timestamp();

    Result -- it read in 10,000 files in under 2 seconds!  A 100X performance improvement!
